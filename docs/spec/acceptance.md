# 验收总纲（SPEC/acceptance）

> 各分册"验收"节的汇总与总闸。原则：可执行命令或可对照契约，禁止散文承诺。

## 1. 三条性能靶 〔定稿〕

| # | 靶子 | 测法 |
|---|---|---|
| ① | 单机 500 并发 4K 直链 Range 客户端不掉速 | k6/自研压测脚本：500 VU 并发 Range 拉流（0-100% 随机偏移，恒定吞吐），断言每连接吞吐无衰减、`p95 首字节 < 50ms`；对照机器记录 sendfile 生效（strace/procfs） |
| ② | 百万级 Item 全库查询 P95 < 100ms | 种子脚本生成 1M 条目（含关联表与物化载荷）；对 /Items 浏览/筛选/搜索端点跑固定查询集（≥20 种组合 × 1000 次），PG `auto_explain` 抽查无顺序扫描 |
| ③ | 增量感知新文件 < 5s | fsnotify 监视下落盘新媒体文件，计时到条目可浏览（含探测），断言 < 5s；网络盘（inotify 失效）场景走定时扫描兜底，不参与本靶 |

压测环境、机器规格、结果记录格式在本册附录固定（实现时填）。

## 2. 兼容验收 〔定稿〕

- **LinWeb 端到端**：以 LinWeb 真实前端跑全套用户旅程（登录→浏览→详情→
  直连播放→进度→弹幕→房间）对 Serata 后端全绿——这是兼容矩阵的最低门槛。
- **Emby 客户端抽查**：Infuse / 官方安卓客户端连 Serata，浏览与播放可用
  （矩阵逐项记录）。
- **抓包对照**：4.8 真实服务器响应留档（`docs/spec/snapshots/`），端点形状
  对照测试引用。

## 3. 质量验收 〔定稿〕

- Go：单测 + Testcontainers 集成（PG/ffmpeg）+ 上述压测脚本进 CI（阈值放宽跑）。
- Web：真浏览器断言套件（沿 LinWeb 哲学）+ Emby 联调 checklist（web.md §8）。
- 发布门：amd64/arm64 镜像构建 + fixture 迁移测试（emby-migration.md §4）。

## 4. 非功能记账 〔定稿〕

- `/metrics` 必含：会话计数与模式分布、查询延迟直方图、扫描速率、转码会话、
  PG 连接池占用。
- 直传占比仅进日志/指标，不进看板（看板定稿口径）。
