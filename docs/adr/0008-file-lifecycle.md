# 文件生命周期：扫描器无权删除用户数据

与 Emby 故意分歧：Emby 扫描发现文件缺失即标 missing / 按配置删除条目。Serata 的原则是**删除永远是用户的决定，扫描器只观察不销毁**：

1. **洗版**：文件消失 → Item 进入 **Unbound**（数据全保留：元数据、弹幕、进度、收藏、合集关系；默认不进浏览列表）→ 符合 Emby 命名规范的新文件到来 → 按同一解析规则匹配 → 自动重新绑定，数据原样合回。
2. **真删除**：仅发生在用户 UI 主动删除时，弹窗二选一：**彻底删除**（条目 + 元数据 + 弹幕 + 进度全删）/ **保留数据**（仅解除绑定，等新文件）。
3. 扫描的自动清理只限孤儿缓存与临时文件，永不清 Item 数据。

## Consequences

- Unbound 条目对兼容客户端不可见，但 API 保留（管理员视图可列出）。
- 重绑定匹配规则 = Emby 命名规范解析，与初次扫描共用同一段代码，禁止出现两套解析器。
