# 插件系统唯一机制：goja 内嵌 JavaScript

Go 没有可用的动态加载（原生 plugin 仅 Linux 且极脆），插件机制选定 **goja（Go 内嵌的 ES2022 解释器）为唯一机制，不做第二套**，v1 开放面限定：自定义 Provider（刮削源）、元数据后处理、媒体事件钩子。

## Considered Options

- WASM（wazero）：沙箱强、多语言，但插件作者开发门槛高，v1 生态起不来。
- 外挂进程 / HTTP sidecar：任何语言可用，但要求用户装运行时，交付破坏单二进制哲学。
- Go 原生 plugin 包：平台限制致命，直接排除。

## Consequences

- 权限模型照 Emby 插件模式：**信任安装、完整宿主 API、无权限确认弹窗**。goja 天然没有文件系统与任意进程能力，这是解释器的技术事实而非权限设计；宿主 API（网络、存储、日志、事件）全量开放给插件。
- 未来若需要更强沙箱，演进方向是同一套宿主 API 换 WASM 执行器，插件接口签名保持不变。
